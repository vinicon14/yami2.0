═══════════════════════════════════════════════════════════════════════════
⚡ INÍCIO RÁPIDO
═══════════════════════════════════════════════════════════════════════════

PARA WINDOWS
───────────
1. Baixe: YAMI-Portable.zip
2. Extraia a pasta em um local seguro
3. Abra a pasta e execute: run.bat
4. O YAMI será iniciado automaticamente
5. Siga as instruções na tela para configurar


PARA ANDROID
─────────────
1. Baixe: yami.apk
2. Abra o gerenciador de arquivos ou navegador de downloads
3. Toque em yami.apk
4. Confirme a instalação (talvez precise habilitar "Fontes desconhecidas")
5. O YAMI estará na tela inicial - toque para abrir


═══════════════════════════════════════════════════════════════════════════
📋 REQUISITOS MÍNIMOS
═══════════════════════════════════════════════════════════════════════════

Windows:
  • Windows 10 ou 11 (64-bit)
  • 2GB de RAM
  • 100MB de espaço livre
  • Conexão com internet

Android:
  • Android 8.0 ou superior
  • 2GB de RAM
  • 50MB de espaço livre
  • Conexão com internet


═══════════════════════════════════════════════════════════════════════════
🔒 VERIFICAÇÃO DE INTEGRIDADE
═══════════════════════════════════════════════════════════════════════════

Para garantir que os arquivos foram baixados corretamente, você pode
verificar os hashes SHA256 fornecidos em CHECKSUM.txt.

Windows PowerShell:
  (Get-FileHash "YAMI-Portable.zip" -Algorithm SHA256).Hash

Linux/Mac:
  sha256sum YAMI-Portable.zip


═══════════════════════════════════════════════════════════════════════════
❓ PERGUNTAS FREQUENTES
═══════════════════════════════════════════════════════════════════════════

P: Preciso instalar algo antes?
R: Não para Windows (tudo está no ZIP). Para Android, apenas o sistema
   operacional de base.

P: O arquivo é seguro?
R: Sim! Você pode verificar o hash SHA256 em CHECKSUM.txt para confirmar
   a integridade do arquivo.

P: Consigo usar offline?
R: Parcialmente. Algumas funcionalidades de IA requerem internet, mas
   muitas podem funcionar offline.

P: Existe suporte?
R: Consulte a documentação incluída. Para bugs, visite o repositório GitHub.
