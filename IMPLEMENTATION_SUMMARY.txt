HOW TO USE
================================================================================

1. INITIALIZE DATABASE
   
   import { initializeDatabase } from './database/index.mjs';
   
   const { db, syncEngine, syncAPI } = await initializeDatabase({
     syncApiPort: 18900,
     peerUrl: process.env.YAMI_SYNC_PEER_URL,
     autoSync: true
   });

2. USE FOR AUTO-PANEL
   
   import { initPanelDatabase, getPanelState, savePanelState } 
     from './database/integration-auto-panel.mjs';
   
   const { db } = await initPanelDatabase({...});
   
   // Replace readState() with:
   const state = getPanelState(db);
   
   // Replace saveState(next) with:
   savePanelState(db, next);

3. CONFIGURE SYNC
   
   export YAMI_SYNC_PEER_URL="http://other-device:18900/sync"
   export YAMI_SYNC_KEY="secure-api-key"

4. MULTI-DEVICE SYNC
   - Device A changes setting
   - DB logs change with timestamp
   - Auto-sync in 30 seconds
   - Device B receives change
   - Device B applies change
   - All devices synchronized ✓

5. OFFLINE SCENARIO
   - Device A goes offline
   - Changes logged locally
   - Reconnects
   - Auto-sync resumes
   - All changes merged
   - Consistent state ✓
