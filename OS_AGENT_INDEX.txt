================================================================================

COMECAR AGORA:
  1. Ler QUICK_START_OS_AGENT.md
  2. Executar: python -m runtime.os_agent.cli interactive
  3. Tentar um comando: "execute abrir chrome"

  1. Ler README.md (estrutura)

  2. Ver exemplos em INTEGRATION.md

  python -m runtime.os_agent.__main__

  python -m runtime.os_agent.examples [1-10]

================================================================================
                         PRINCIPAIS COMPONENTES
================================================================================

ORCHESTRATOR:
  - Coordena o pipeline completo
  - Planejar -> Autorizar -> Executar -> Observar
  - Interface simples: orch.execute(comando)

PLANNER:
  - Reconhece padroes em linguagem natural
  - Decompe em ActionSteps
  - Retorna ActionPlan estruturado

PERMISSION MANAGER:
  - 4 niveis: SAFE / NOTIFY / CONFIRM / BLOCKED
  - Cache de aprovacoes (sessao/permanente)
  - Callback customizavel

EXECUTORS (7 dominios):
  - Cada um eh modular e independente
  - Implementam acoes atomicas
  - Dispatch automatico

SYSTEM MONITOR:
  - Snapshots periodicos do sistema
  - Deteccao de mudancas
  - Contexto para planejador

ERROR HANDLER:
  - 5 estrategias de recuperacao
  - Fallback map customizavel
  - Retry adaptativo
